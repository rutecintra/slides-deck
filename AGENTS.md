# Project conventions

- Write code, filenames, identifiers, comments, documentation, and application controls in English.
- Keep presentation content and speaker notes in Portuguese.
- Every presentation must have audience and speaker modes using the shared player. Never create duplicate source decks for these modes.
- Preserve existing stable deck URLs. Add presentations under `decks/<english-slug>/`.
- Keep chapter references and source attribution with slides. Distinguish evidence from illustrative examples in speaker notes.
- Update speaker notes whenever slide content changes. Retain specific examples and activity instructions.
- Preserve the SIP workshop's approved content and visual design unless explicitly asked to change it.
- The public site also exposes source JSON and speaker notes. Do not put credentials or confidential content in this repository.
- Run `npm test` and `npm run build` before publishing. Inspect changed slide layouts in a browser when the environment supports it.
- A push to main publishes GitHub Pages. Do not change repository visibility without explicit authorization.
